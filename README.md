# Speech-to-Text proof-of-concept application

## Overview

This repo, `speech-to-text`, is a proof-of-concept application that allows a user to
transcribe speech to text.

The application is organized into three sub-applications:
* Frontend
* Backend
* OpenAI Whisper model

## Running locally

The application can be run locally by running the `docker-compose.yml`. After cloning
the repo, run the following commands:

```
cd speech-to-text
docker compose -f docker-compose.yml
```
